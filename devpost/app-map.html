What the app does

Qué hace la app

A teacher types a class topic and picks a language. Loter-IA makes a Lotería with 24 picture cards, lets the teacher swap any card, and gives two PDF files to print: the boards and the cards to cut out. The teacher can also call the cards on screen.

Un maestro escribe el tema de su clase y elige un idioma. Loter-IA crea una Lotería de 24 cartas con dibujo, deja cambiar cualquier carta y entrega dos archivos PDF para imprimir: las tablas y las cartas para recortar. El maestro también puede cantar las cartas en la pantalla.

  3. Stop 2 · The recipeParada 2 · La receta

    lib/deck.js — search for— busca export async function buildDeck

    The heart of the app. It asks the AI for 48 ideas, looks for pictures of each one, and has the AI review them. The first 24 good cards become the deck; the rest are kept as spares for Regenerate. If 24 are not reached it asks for more, up to four rounds, telling the AI which ideas had no picture. If it still falls short, the teacher is told to try a broader topic.

    El corazón de la app. Le pide 48 ideas a la IA, busca dibujos para cada una y hace que la IA las revise. Las primeras 24 cartas buenas forman la baraja; las demás se guardan como repuesto para Regenerate. Si no llega a 24, pide más, hasta cuatro rondas, y le dice a la IA qué ideas no tenían dibujo. Si aun así no alcanza, le avisa al maestro que pruebe un tema más amplio.

    See the codeVer el código 
    export async function buildDeck({ topic, language }, services) {
  const deck = { topic, language, cards: [], spares: [] };
  const tried = []; // every idea so far, so none is proposed twice
  const unpictured = []; // the ideas the picture library didn't have
  for (let round = 0; round < ROUNDS && deck.cards.length < DECK_SIZE; round++) {
    const ideasSoFar = tried.length;
    // A later round only has to fill the last few cards, and tells the AI which ideas had no picture.
    const request = round === 0
      ? { count: CANDIDATES, avoid: [] }
      : { count: FILL_CANDIDATES, avoid: [...tried], unpictured: [...unpictured] };
    const fresh = await newCards({ topic, language, ...request, existing: allCards(deck) }, services, tried, unpictured);
    for (const card of fresh) (deck.cards.length < DECK_SIZE ? deck.cards : deck.spares).push(card);
    if (tried.length === ideasSoFar) break; // no ideas at all (a nonsense topic): asking again won't help
  }
  if (deck.cards.length < DECK_SIZE) {
    throw new DeckError('too-narrow', `Only ${deck.cards.length} of ${DECK_SIZE} pictures were found for this topic.`);
  }
  return deck;
}

    function cardElement(card, index) {
  const item = document.createElement('li');
  item.className = 'card';
  item.dataset.index = index;
  item.style.setProperty('--card-color', COLORS[index % COLORS.length]);
  const art = pictureElement(card);
  const name = document.createElement('p');
  name.className = 'name';
  name.textContent = card.name;
  const regen = document.createElement('button');
  regen.type = 'button';
  regen.className = 'regen';
  regen.textContent = '↻ Regenerate';
  regen.setAttribute('aria-label', `Regenerate ${card.name}`);
  const note = document.createElement('p');
  note.className = 'note';
  note.setAttribute('role', 'status');
  item.append(art, name, regen, note);
  return item;
}

A practice to reuse: try real results early

What happened in this project:

  • The first working step, a deck made from a topic, was built before anything else. It was tried by hand in the browser and by a script that builds real decks for six school topics: scripts/coverage.js, run with npm run coverage.
  • The script showed problems the plan had not predicted: planet Earth drawn as garden soil, a fairy-tale dwarf for “dwarf planet”, lions among the farm animals. The fixes were a different AI model, stricter picture matching (hasKeyword in lib/arasaac.js), and a second look by the AI at every card (reviewCards in lib/nova.js).
  • Seeing the app work early also changed the plan for printing. It was going to be the browser's print window; it became one PDF file with all the boards, made in lib/pdf.js.
  • Each change is written down with its reason in devpost/checklist.md, under Revisions.

On another project: build the smallest step that can really be used, try it with real examples before building around it, and write down what changed and why.

Una práctica para repetir: prueba resultados reales desde el principio

Lo que pasó en este proyecto:

  • El primer paso que ya funcionaba, una baraja a partir de un tema, se construyó antes que todo lo demás. Se probó a mano en el navegador y con un programa que arma barajas reales de seis temas escolares: scripts/coverage.js, que se corre con npm run coverage.
  • El programa mostró problemas que el plan no había previsto: el planeta Tierra dibujado como tierra de jardín, un enano de cuento para “planeta enano”, leones entre los animales de la granja. Las soluciones fueron otro modelo de IA, una búsqueda de dibujos más estricta (hasKeyword en lib/arasaac.js) y una segunda revisión de la IA a cada carta (reviewCards en lib/nova.js).
  • Ver la app funcionando desde temprano también cambió el plan para imprimir. Iba a ser la ventana de impresión del navegador; terminó siendo un solo archivo PDF con todas las tablas, hecho en lib/pdf.js.
  • Cada cambio está anotado con su motivo en devpost/checklist.md, en la parte de Revisions.

En otro proyecto: construye el paso más chico que ya se pueda usar, pruébalo con ejemplos reales antes de construir alrededor de él, y anota qué cambió y por qué.

Run it again

Para volver a encenderla

  • You need Node.js 24 and a private .env file with an Amazon Bedrock key. Copy .env.example to .env and fill it in.
  • npm install the first time, then npm start, then open http://localhost:3000.
  • npm test runs the tests. They need no internet and no key.
  • Necesitas Node.js 24 y un archivo privado .env con una llave de Amazon Bedrock. Copia .env.example como .env y llénalo.
  • npm install la primera vez, luego npm start, y abre http://localhost:3000.
  • npm test corre las pruebas. No necesitan internet ni llave.
